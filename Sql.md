GENERATED ALWAYS AS IDENTITY ---> This means PostgreSQL does not allow you to manually provide a value.
GENERATED BY DEFAULT AS IDENTITY ---> We can provide values but need to be unique.

Singleton Check Constraint

SQL
CHECK(singleton)

Equivalent to:

SQL
CHECK(singleton = TRUE)

What it does
The value must always be: TRUE

Allowed:
singleton = TRUE

Rejected:
singleton = FALSE

Why combine CHECK + UNIQUE?
Let's see.

Constraint 1
CHECK(singleton)
forces:
singleton = TRUE
only.

Constraint 2
UNIQUE(singleton)
allows only one occurrence of TRUE.

What UNIQUE means
No two rows can have the same value.
